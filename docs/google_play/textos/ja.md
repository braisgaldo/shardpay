```
ShardPay：グループの割り勘
```

**Descripcion corta** (36/80)

```
グループの支出を分担し、レシートをカメラで読み取ります。無料・広告なし。
```

**Descripcion larga** (549/4000)

```
割るのはレシート、友情ではなく。

ShardPay はグループ内で誰がいくら払ったかを記録し、誰が誰にいくら借りているかを計算します。表計算も、言い争いも、記憶しておくことも不要です。

カメラでレシートを読み取ります
レシートを撮影すると、ShardPay が明細・金額・合計を認識します。さらに明細の合計が印字された合計と一致するかを確認し、合わないときは知らせます。認識はすべて端末内で行われ、写真が外部サービスに送られることはありません。

好きなように分けられます
ワンタップで均等に、あるいは明細ごとに一人ひとりの割合を指定して。

わかりやすい残高
誰が誰にいくら借りているかを表示し、すべてを清算するのに必要な最小限の支払い回数を提案します。

一瞬で招待
リンクか QR コードを共有するだけ。まだアカウントのない人も追加できます。

あなただけのもの
広告なし。分析なし。テレメトリなし。データの販売もありません。

14 言語・13 テーマ
13 種類の配色。それぞれにライトとダークがあり、システム設定に追従する選択肢もあります。

本当に無料
有料版も、制限された機能もありません。開発者にコーヒーをおごる選択肢はありますが、それで何かが解放されることは一切ありません。
```
